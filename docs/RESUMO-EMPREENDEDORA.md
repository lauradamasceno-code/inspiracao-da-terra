# Lemaréz Gestão: resumo para a empreendedora

O Lemaréz Gestão é um painel para cadastrar clientes, vendas e custos e ver como a loja está indo. Ele usa o catálogo de perfumes da Lemaréz, com os códigos IF (femininos) e IM (masculinos).

## O que você faz nele
- Cadastrar clientes (nome, CPF, endereço, e-mail, telefone e nascimento), só com a autorização do cliente.
- Lançar vendas e gastos com os tipos, categorias e formas de pagamento que a Lemaréz já usa. A quantidade é sempre um número inteiro.
- Marcar a fragrância vendida pelo catálogo ou como perfume extra, quando o pedido é sob demanda.
- Filtrar por cliente, mês, fragrância, categoria e forma de pagamento.
- Ver no painel o top 10 de perfumes, o saldo e os clientes que mais compram.
- Ver o DRE do ano, mês a mês, no mesmo formato da planilha financeira.
- Gerar, quando quiser, um catálogo em PDF com a identidade visual da Lemaréz, sempre com as fragrâncias atuais.
- Baixar as listas e o DRE em CSV.

## O que é de verdade e o que é simulado

| | O que é |
| --- | --- |
| Funciona de verdade | A tela, os formulários, os filtros, o ranking, o DRE, o catálogo em PDF, o catálogo de 54 femininos e 52 masculinos, o CSV, o perfume extra e as regras de privacidade (autorização, CPF validado e oculto, exclusão do cliente). |
| Simulado na apresentação | Os clientes, as vendas, os custos e o histórico mensal (inclusive o do DRE) são fictícios. Os dados ficam só no navegador de quem apresenta e não há login. |
| Ainda não existe | O banco de dados definitivo com login, a importação das vendas reais da planilha financeira, o backup automático e o texto de privacidade revisado por um profissional jurídico. |

## Seus dados e a LGPD
Os dados dos clientes são seus, e só você deve ter acesso a eles. Por isso o app pede a autorização do cliente no cadastro, deixa o CPF opcional e parcialmente oculto na tela e permite ver, corrigir, baixar ou excluir os dados de qualquer cliente. Os dados ficarão num banco de dados com login e cópia de segurança, que será criado com você. Não usaremos Google Planilhas.

## Próximos passos
1. Criar o banco de dados com login só para você e cópia de segurança.
2. Trazer as vendas reais da planilha financeira para dentro do app.
3. Testar o app por uma semana na loja e ajustar o que atrapalhar.
4. Revisar o texto de privacidade com um profissional jurídico antes de usar com clientes.
